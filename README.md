# CorelFlow Studio — Personal All-In-One PDF, CDR & Image Media Suite

An all-in-one local toolkit designed to handle all your PDF conversions, CorelDRAW exports, image format conversions, cropping, and word/text editing in one place—with **zero API keys, 100% privacy, and completely free**.

---

## 🛠️ Included Tools & Modules

### 1. ⚡ PDF ➔ CDR (CorelDRAW)
- Convert any PDF into authentic CorelDRAW `.cdr` files.
- Version selector: **CorelDRAW 2024 (v25), 2022, 2020, 2019, X8, X7 (print shop standard), X6, X5**.
- Prepress options: Font Outlining / Text to Curves, CMYK separations, and 3mm Bleed.
- Universal Print-Shop Pack (`.cdr` + `.cmx` + `.svg` + `.png` + prepress notes).

### 2. 🔄 Universal Format Converter
- **PDF ➔ PNG / JPG / WebP**: Export any page or all pages at 150 DPI, 300 DPI (Prepress Quality), or 450 DPI. Batch export all pages as a `.ZIP`.
- **Image Format Converter**: Convert between PNG, JPEG, and WebP with quality compression sliders and resizing.
- **Images ➔ Combined PDF**: Stitch multiple PNGs, JPGs, or WebP images into a single clean PDF document.

### 3. ✂️ PDF Image & Area Cropper
- Visual interactive page inspector powered by Cropper.js.
- Drag the crop box over *any* image, logo, graphic, or section of the PDF.
- Options:
  - **Download Cropped Image** as high-res PNG or JPEG.
  - **Save Cropped Area as New PDF** (modifies PDF page boundaries).

### 4. ✏️ PDF Word & Text Modifier ("Change words in that PDF")
- **Find & Replace Words**:
  - Automatically scans PDF text streams using PDF.js.
  - Locates matching words and seamlessly stages replacements with matching fonts and sizes.
- **Visual Click-to-Edit & Whiteout**:
  - Click anywhere on the PDF page preview to place an editable patch.
  - Custom font family (Helvetica, Times, Courier), font size, text color, and mask/whiteout background.
- **Download Updated PDF** with all word modifications saved.

### 5. 💻 Windows 1-Click Corel Automation
- Optional downloadable `.bat` runner for users with CorelDRAW installed on Windows.
